任务栏上，两行就够

把额度放进 Windows 任务栏，按设定间隔轮播。每个平台按窗口分行：第一行是短窗口，第二行是周额度，各自带着重置时间。

  • 1
    5h 与周额度都有第一行「5h 额度 + 5h 重置时间」，第二行「周额度 + 周重置时间」，同一行里额度和时间各自成段。
  • 2
    只有周额度第一行放额度，第二行放周重置时间，不挤在一行里。
  • 3
    余额与积分类第一行余额或积分，第二行显示这组数据是什么时候刷新的。

点击任务栏上的额度，直接打开总览；轮播间隔与后台刷新频率互不影响。

一个窗口，收齐所有额度

总览、悬浮窗、任务栏共用同一份数据；配色与字体按自己的习惯调，不用记每个平台在哪里看。

额度总览

各平台卡片列出 5h 与周剩余额度、重置与刷新时间，支持搜索和「已启用 / 需要关注」筛选。

颜色就是状态

绿、黄、红对应剩余多少；环形图和进度条同步着色，扫一眼就知道哪家快用完。

字体与排版

AI 名称与额度数字的字体、字号、粗细分开调整，中文与西文数字可分别选字体，并提供混排预览。

余额与订阅

DeepSeek、DMXAPI、智谱开放平台显示账户余额；ChatGPT 与豆包同步订阅方案和到期时间。

自动刷新

后台按设定间隔更新，托盘常驻；重置时间可切换具体时刻或倒计时，到点等待新额度。

随桌面收放

可折叠成小条贴在角落或任务栏上方，也可拖到屏幕任意位置；开机自启与轮播顺位都能调。

装好就能用

从 GitHub Releases 取最新版本：MSI 安装包会装到 Program Files 并创建开始菜单项；也可以直接用绿色版单文件 exe。

数据只留在本机

不经过任何中转服务器，也没有账号体系。

凭证本地加密

API Key 与客户端登录态加密后写在本机配置文件里，只在查询额度时向对应服务商发请求。

不收集使用数据

没有埋点与统计上报；卸载后本机配置可一并删除，仓库代码完全公开。

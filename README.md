# QuotaBoard

Windows 桌面小工具，把常用 AI 服务的额度与余额汇总到一个悬浮窗里，随时瞄一眼就知道还剩多少。

官网：<https://othrik.github.io/QuotaBoard/>

## 支持的平台

| 平台 | 展示内容 |
| --- | --- |
| ChatGPT | 5 小时 / 每周限额 |
| 豆包 | 5 小时 / 每周额度 |
| Gemini | 5 小时 / 每周额度 |
| 智谱清言 | 会员积分 |
| DeepSeek开放平台、DMXAPI、智谱开放平台 | 账户余额 |
| 其他 | 可手动添加任意条目 |

## 特性

- 额度总览：各平台卡片、余额与多窗口剩余额度、重置与刷新时间，支持搜索与状态筛选
- 双环形图与进度条，绿 / 黄 / 红表示剩余状态
- 可折叠成小条，贴在桌面角落或任务栏上方
- AI 名称与额度数字的字体、粗细、字号可分别调整，中西文可分别选字体
- 「任务栏常驻额度」：把额度直接放进任务栏，随时间轮播，点击打开总览
- 后台定时刷新，托盘常驻，支持开机自启

## 安装

- **MSI 安装包**（推荐）：从 [Releases](https://github.com/Othrik/QuotaBoard/releases) 下载，安装后在开始菜单启动
- **绿色版**：单文件 exe，直接运行
- 系统要求：Windows 10 / 11（64 位）

## 使用提示

- 任务栏两行按窗口拆分：第一行是 5h 额度与 5h 重置时间（如 `5h 94% 03:05重置`），第二行是周额度与周重置时间（如 `周 29% 11-07 20:01重置`）；只有周额度的平台第一行额度、第二行重置时间，余额类平台第一行余额、第二行刷新时间。平台由左侧图标区分，订阅方案与完整明细在展开面板和总览中查看
- 设置 → 通用与显示：轮播间隔（1–300 秒，默认 5 秒）、重置提示在具体时间 / 倒计时之间切换，两者与后台刷新频率独立
- 每张总览卡片的「任务栏轮播」与「悬浮窗」独立控制，取消展示不影响后台查询；「AI 显示顺序」页支持拖动与置顶/置底（Alt+方向键）
- 设置 → 字体设置：任务栏和悬浮窗独立配置，中文与西文/数字的字体、字号、粗细分开调整，并提供混排预览
- 任务栏、开机自启、刷新间隔也可在托盘菜单切换；双击托盘图标打开额度总览
- 智谱清言、豆包：先在对应客户端登录一次，之后自动沿用本机登录态
- 其他平台：在设置里填入 API Key，可先点「测试连接」确认可用

## 隐私

- 凭据加密后仅保存在本机配置文件，不上传任何服务器
- 只有查询额度时会向对应服务商发请求，不收集使用数据

## 开发

```bash
pip install -r requirements.txt
python main.py                              # 运行
python -m tests.tests_smoke                 # 冒烟测试
python -m PyInstaller QuotaBoard.spec       # 打包 exe
```

MSI 安装包需要 WiX Toolset 3.14。

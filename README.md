# QuotaBoard

Windows 桌面小工具，把常用 AI 服务的额度与用量汇总到一个悬浮窗里，随时瞄一眼就知道还剩多少。

## 支持的平台

| 平台 | 展示内容 |
| --- | --- |
| ChatGPT | 5 小时 / 每周限额 |
| 豆包 | 5 小时 / 每周额度 |
| Gemini | 5 小时 / 每周额度 |
| 智谱清言 | 会员积分 |
| DeepSeek开放平台、DMXAPI、智谱开放平台 | 账户余额 |
| 其他 | 可手动添加任意条目 |

## 特性

- 额度总览面板：各平台卡片、余额与多窗口剩余额度、重置与刷新时间，支持搜索和状态筛选；原有配置收进右上角“设置”
- 双环形图与进度条，绿色 / 黄色 / 红色表示剩余状态
- 可折叠成小条，贴在桌面角落或任务栏上方
- AI 名称与额度数字的字体、粗细、字号可分别调整
- 后台定时刷新，托盘常驻，支持开机自启
- 可选「任务栏常驻额度」，把额度直接放进任务栏，点击查看详情

## 安装

- **MSI 安装包**（推荐）：从 [Releases](https://github.com/Othrik/QuotaBoard/releases) 下载，安装后在开始菜单启动
- **绿色版**：单文件 exe，直接运行
- 系统要求：Windows 10 / 11（64 位）

## 使用提示

- 设置 → 通用与显示 → 任务栏显示 → 轮播间隔，可调每个平台停留时间（1–300 秒，默认 5 秒）；保存后生效，与后台额度刷新频率独立
- 设置 → 通用与显示 → 重置提示，可在具体时间和倒计时之间切换；用于任务栏及桌面吸附条的额度耗尽提示，分钟级自动更新，不额外查询接口。到点后等待新额度响应，不推断额度已恢复
- DeepSeek开放平台的普通 API Key 可读取各币种总余额、充值余额、未过期赠送余额与余额是否足够调用；总览分项展示、悬浮详情同步。金额至少两位、最多四位小数，省略末尾无效零，多币种不相加。今日/本月消费及 Token 账单不在此公开余额接口中
- 智谱开放平台使用 API Key 读取人民币可用余额，无需网页登录；优先查询 `open.bigmodel.cn/api/biz/account/query-customer-account-report`，必要时回退同一智谱平台的 `www.bigmodel.cn` 域名。此控制台接口未列入公开推理 API 文档，显示的是预付费余额，不是 Coding Plan 额度
- Open AI API Platform、Kimi 与火山方舟暂时移出平台列表、展示和自动查询；旧配置保留，便于后续恢复
- 设置 → 字体设置：中文与西文/数字分别选字体；任务栏和悬浮窗独立配置。悬浮窗名称、额度/环形数字、时间/辅助文字分别可调字号与粗细，并提供混排预览
- 总览卡片可分别选择“任务栏轮播”和“悬浮窗”，两者独立；取消悬浮窗展示不会影响总览或后台查询
- 设置中的“AI 显示顺序”独立页面支持拖动、置顶/置底、上移/下移（Alt+方向键）和恢复默认，保存后同步各展示界面
- 订阅到期：豆包读取订阅接口；ChatGPT 读取本机 Codex 登录态中的订阅有效期（登录时记录，续费后可能需重新登录更新）；Gemini 当前额度接口不返回到期日期，显示未获取
- 任务栏在 AI 名称右侧展示已获取的订阅方案，总览和设置右上方显示 QuotaBoard 版本
- 点击任务栏常驻额度直接打开总览。每张卡片的“任务栏轮播”独立控制是否轮播，取消勾选仍在总览显示、查询和刷新；选择会自动保存，全部取消时隐藏任务栏额度
- 双击托盘图标或选择“额度总览”打开聚合面板；右上角“设置”进入原有配置，卡片“配置”可直达对应平台
- 智谱清言、豆包：先在对应客户端登录一次，QuotaBoard 会自动读取登录态并存到本机，之后客户端关掉也能显示
- 其他平台：在设置里填入 API Key，可先点「测试连接」确认可用
- 任务栏常驻、开机自启、刷新间隔等都在设置页或托盘菜单里切换

## 隐私

- 凭据加密后仅保存在本机配置文件，不上传任何服务器
- 只有查询额度时会向对应服务商发请求，不收集使用数据

## 开发

```bash
pip install -r requirements.txt
python main.py                              # 运行
python -m tests.tests_smoke                 # 冒烟测试
python -m PyInstaller QuotaBoard.spec       # 打包 exe
```

MSI 安装包需要 WiX Toolset 3.14。

## 版本

1.1.52 DeepSeek 计费时段改为 ChatGPT 风格的强调文字：移除圆点和胶囊式状态感，文字与平台名同基线，仅以低对比度暖橙或薄荷色底强调“高峰／空闲”。

1.1.51 优化 DeepSeek 计费时段 UI：高峰改为暖橙色、空闲改为低饱和青绿色，徽标缩小并加入状态圆点；任务栏、总览和悬浮窗统一视觉，避免高峰被误认为请求失败。

1.1.50 DeepSeek 任务栏计费时段改为彩色徽标：高峰红色、空闲绿色、时段待确认灰色，彩色文字配浅色强调背景，任务栏与悬浮窗吸附条同步显示。

1.1.50 修复任务栏组件升级问题：hook 组件更新时旧组件仍驻留在资源管理器里，新旧互相干扰会导致额度不显示；现在宿主启动时会检测旧组件并自动重启一次任务栏再注入，升级后无需手动重启。

1.1.49 为 DeepSeek 增加官方计费时段标注（北京时间工作日 09:00–12:00、14:00–18:00 为高峰，周末及节假日为空闲），本地时钟自动切换，不额外查询 API。内置已核实的 2026 年节假日，未知年度的工作日高峰窗口显示“时段待确认”，避免误报。

1.1.49 为任务栏额度增加变化动画：按各 AI 上次实际播出的数据比较，变化后短暂淡入并轻微上移；首次显示、仅刷新时间变化不触发，遵循 Windows 动画开关。仅一个 AI 时常驻显示，详情刷新复用原有显示元素，避免重复切换和闪动。

1.1.48 新增任务栏轮播间隔设置（1–300 秒，默认 5 秒）；暂时移除 Open AI API Platform 的入口、展示和后台查询，保留既有配置，ChatGPT 会员额度照常显示。

1.1.47 统一平台名称为“智谱开放平台”“DeepSeek开放平台”“Open AI API Platform”，同步旧缓存和任务栏；暂时移除 Kimi 与火山方舟入口及自动查询，保留既有配置。

1.1.46 核对 DeepSeek 原始余额精度后，改为至少两位、最多四位小数，省略末尾无效零；真实第三、四位仍保留。

1.1.45 总览与任务栏金额前统一显示“余额 ”，金额及货币分项固定四位小数（包含末尾零）。

1.1.44 余额类平台的任务栏轮播增加“余额 ”前缀，并以固定可见间距保留文字与金额之间的空格。

1.1.43 将 5h/周标签统一为黑色，额度耗尽时的重置时间和倒计时保持红色，百分比继续按剩余状态着色。

1.1.42 扩展 DeepSeek 余额详情：充值/赠送余额分列、各币种保持独立、API 可调用状态、最多四位小数；新增额度耗尽提示的具体时间/倒计时切换，倒计时原位自动更新。

1.1.41 修复智谱开放平台余额查询：改用可接受 API Key 的账户报表接口，新增官方域名回退、精细余额与累计消费/冻结金额；不再把失效旧路径误判为无法自动查询。
